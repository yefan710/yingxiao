## Fixed Structure

- `part1`: 头图，功能上新图。
- `part2`: 功能汇总图。
- `part3`: 各个功能配图。

## Recommended Type Mapping For This PRD

- `Agent 生图能力`: 功能说明 / 2图混合层。Reason: 对话框、选图、生成效果、修改能力需要多图组合。
- `批量生图能力`: 功能配图。Reason: 商品筛选 + 多类型素材勾选 + 批量提交，一张后台流程截图可以证明。
- `生成效果确认`: 功能配图。Reason: 成功/失败/执行中状态、查看大图、移除、发布动作属于单界面证明型功能。
- `发布至商品`: 功能说明 / 2图混合层。Reason: 需要说明单张/多张、SPU/SKU、坑位选择、发布至原坑位。
- `历史记录/计划管理`: 功能配图。Reason: 按计划查看成功失败数和生成中商品，适合单界面展示。
- `权益/点数`: 功能配图或小型说明图。Reason: 需要解释免费点数、付费点数、套餐外内购和扣点。

## Screenshot Rule

All backend UI and product UI must be pasted from real screenshots/design frames through mask coordinates. Do not let image generation redraw JD/Jingmai UI.
